# مَنْهَل

حجز حصص التعلم الذاتي في مركز مصادر التعلم بمدرسة بلج بن عقبة الفراهيدي للبنين (٧-٩).

التطبيق صفحة ويب قابلة للتثبيت، وقاعدة Supabase في فرانكفورت، وغطاء أندرويد من نوع WebView. اسم التطبيق يُعرَّف مرة واحدة في `APP_NAME` داخل `js/config.js`.

## المعاينة المحلية

اترك `SUPABASE_URL` و`SUPABASE_ANON_KEY` فارغين. التطبيق يخزّن البيانات في المتصفح ويطبّق قواعد الحجز نفسها.

```bash
npm install
npm test
npm run build
python3 -m http.server 4173
```

أرقام الملفات الأولية للمعاينة وللتشغيل الأول بعد زرع القاعدة:

| الرقم | الاسم | الدور |
|---|---|---|
| 900001 | يعقوب المعمري | مشرف عام |
| 900002 | أحمد السناني | مساعد مدير |
| 900003 | محمد النخيلي | مساعد مدير |
| 900004 | محمود هلال المعمري | أخصائي المركز |
| 900005 | د.سالم المعمري | مدير المدرسة |

بدّل هذه الأرقام من شاشة الكادر: نموذج إضافة الموظف ظاهر مباشرة، بالاسم ورقم الملف والوظيفة.

ست حصص تبقى محجوزة كل أسبوع باسم «حصة المادة»: الأحد الرابعة لغة عربية، الاثنين الرابعة علوم، الثلاثاء الرابعة رياضيات والخامسة تربية إسلامية، الأربعاء الخامسة لغة إنجليزية، الخميس الرابعة الدراسات الاجتماعية.

## النشر

1. أنشئ مشروع Supabase في منطقة فرانكفورت `eu-central-1`. لا تستخدم منطقة في الهند.
2. نفّذ بالترتيب: `supabase/schema.sql` ثم `supabase/rls.sql` ثم `supabase/seed.sql` ثم `supabase/realtime.sql`.
3. انشر دالة `supabase/functions/login`. التحقق من JWT لهذه الدالة متوقف في `supabase/config.toml` لأن الدخول يكون برقم الملف فقط.
4. ضع عنوان المشروع ومفتاح `anon` فقط في `js/config.js`. مفتاح الخدمة يبقى في لوحة Supabase ولا يُكتب في المستودع.
5. `npm run build` ثم ارفع المجلد إلى موقع Netlify جديد، والمقترح `balaj-lrc`.
6. ارفع `CACHE_VERSION` في `sw.js` مع كل نشر.

اختبار قاعدة البيانات محليًا: `npm run test:sql`.

## أندرويد

المشروع في `android/`، والحزمة `om.balaj.lrc`، والإصدار `1.0.0`. ملف التثبيت الجاهز: `android/manhal-1.0.0.apk`. أثناء البناء تُنسخ صفحات الويب إلى أصول الحزمة، ويفتحها WebView من داخل التطبيق. `LrcJob` يسأل عن الإشعارات غير المقروءة كل ١٥ دقيقة عبر هوية يمررها الجسر `ManhalAndroid`، بلا خدمة أمامية.

نسخة الملف المسلّمة موقّعة بمفتاح التصحيح. توقيع الإصدار النهائي يبقى خارج المستودع في `android/keystore.properties` بالمفاتيح `storeFile` و`storePassword` و`keyAlias` و`keyPassword`.

```bash
cd android
gradle assembleDebug
```

## ملف واحد

`npm run build:single` ينتج `manhal.html`، وهو التطبيق كاملًا في ملف واحد.
